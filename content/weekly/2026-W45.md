## 决策卡

### D1 · 银行自有账户/出金 API 信任链：Arkéa 官方确认 + CERT-In CRAFTY FALCON

- **发生了什么**：Crédit Mutuel Arkéa 官方确认遭网络攻击：攻击者使用银行自有账户向他行转账，再可能换成加密资产；客户账户无资金损失；对约 €1.18 亿/$133M 叙事不确认精确数字但可验证数量级（标 unconfirmed）。印度 CERT-In 警告 AI 辅助团伙 CRAFTY FALCON 针对加密交易所/BFSI：脆弱应用、暴露测试环境、云设施与支付/出金 API，窃取钱包密钥抽干资金。
- **为何重要**：官方确认把链上嫌疑升级为银行网络安全事件；监管硬预警把「出金 API + 预发环境 + 共享密钥」写成同一失败模式。
- **架构冲击**：金库/自有账户支付指令、第三方平台入口、出金 API 与非生产隔离成为同一控制面；DORA 报告与 7×24 监测义务前置。
- **控制域**：资金安全, 出金/支付 API, 第三方平台信任链, 预发/测试环境隔离, 密钥与凭据治理
- **P0**：
  - 盘点自有账户/金库支付指令审批与异常转账熔断
  - 出金与支付 API 强制独立密钥、去共享凭据、加速率/地理异常闸
  - 非生产环境与生产支付面网络隔离；关闭暴露测试入口
- **P1**：
  - 对接链上标签/合规预言机做入金与混币池闸门（Privacy Cash 类余波）
  - 按 CERT-In 建议补 7×24 监测与事件升级剧本
  - 第三方平台接入面做供应商安全问卷与会话审计
- **P2**：
  - 演练「银行侧确认 vs 链上叙事」口径表（精确金额标 unconfirmed）
  - 汇总 BFSI/交易所同类顾问进入季度威胁模型
- **判断**：
  - 精确被盗金额在银行未书面确认前一律 unconfirmed
  - 硬门槛已触发：官方确认 + 监管预警，不可当「仅社媒噪音」

### D2 · Agent 攻防规模化：OpenAI 948 LPE 管线 vs 应用层 Security Reviews / GitBook AI Agent

- **发生了什么**：OpenAI 披露自主漏洞发现/利用/补丁管线单次产出 948 个互异 Linux LPE（候选补丁≠已合并上游；威胁模型为本地提权）。Vercel Security Reviews 约 24h 识别 6817、Agent 修补 1411。同周公开主线还包括 GitBook AI Agent 攻入叙事与 FlashProve 等（见要闻精选；细节以各日权威 Page 为准）。
- **为何重要**：攻方把找洞→打洞→出补丁批量化；守方把应用评审吞吐产品化——防守节奏与披露容量被重写。
- **架构冲击**：端点/多租户假设「低权账户有界」变脆；应用层依赖 Agent 修洞需审计误报与合并门禁；文档/知识库 Agent 写入面成为新攻击面。
- **控制域**：端点与本地提权, 补丁与披露容量, 应用层安全评审, Agent 写入/工具权限, 供应链与文档站点
- **P0**：
  - 加速 Linux 桌面/服务器本地提权补丁队列；限制低权持久账户
  - Agent 自动开 PR/修洞须人工门禁与回滚开关
- **P1**：
  - 对 GitBook/文档站 AI Agent 权限做最小写入与审计日志
  - 将 Security Review 类产品纳入 CI，但 critical 须人工复核
- **P2**：
  - 跟踪 FlashProve 等证明/验证向工具对内部安全研究流程的可迁移性（仅公开叙述，不扩未证实细节）
- **判断**：
  - 948 为官方自述研究管线结果，不夸大成「已远程破门」
  - 候选补丁≠上游已修；运营以发行版公告为准
