#### #1 · AI产品 · OpenAI 发布 ChatGPT Images 2.6：原生 GIF、参考图；API 上 Flare/Sunburst（生成约快 50%）

- **背景**：图像生成是 ChatGPT/Codex/API 高频能力；此前原生一步出 GIF 能力不足，Images 迭代直接影响创作者与开发者工作流。
- **事实**：① @OpenAI 宣布 Images 2.6：可用提示或静图生成动画 GIF，可调速/逐帧编辑；支持参考图复用。② API 推出 GPT-Image-2.6 Flare（低质量最快约 6 秒）与 Sunburst（更高一致性）；称生成速度约提升 50%。③ ChatGPT 与 Codex 全订阅档位、web/桌面/移动可用；另有 SVG 导出与 markup。④ The Verge 等同日报道。
- **为何重要**：官方重大产品发布，主帖近百万曝光。GIF 把「会动的图」变成默认能力，抬高多模态内容与营销工具链预期；API 双型号（快/精）影响计费与集成选型。jargon：Flare/Sunburst=同一代图像模型的速度档与质量档。
- **最早来源·时间**：2026-11-05 07:35 CST · @OpenAI；官网 openai.com/index/introducing-images-2-6/
